# JT-Network – Bug Reports

Dieses Repository dient der zentralen Erfassung und Verwaltung von Fehlern und technischen Problemen auf dem **JT-Network**.

Spieler können hier Fehler melden, die während der Nutzung des Netzwerks auftreten. Die gemeldeten Probleme werden vom Entwicklerteam geprüft und nach Möglichkeit behoben.

## Fehler melden

Fehler können über den [Issues-Bereich](../../issues) dieses Repositorys gemeldet werden.

Ein Bug-Report sollte folgende Informationen enthalten:

- **Beschreibung:** Eine möglichst genaue Beschreibung des Fehlers.
- **Reproduktion:** Die Schritte, mit denen sich der Fehler reproduzieren lässt.
- **Betroffener Server:** Auf welchem Server wurde der Fehler festgestellt?

## Richtlinien

Bitte beachte bei der Erstellung eines Bug-Reports folgende Punkte:

- Prüfe vorab, ob der Fehler bereits gemeldet wurde.
- Erstelle für jeden Fehler ein separates Issue.
- Verwende einen aussagekräftigen Titel und eine sachliche Beschreibung.
- Vermeide doppelte Meldungen und Beiträge ohne Bezug zum Netzwerk.
- Veröffentliche keine persönlichen oder vertraulichen Informationen.

## Bearbeitung von Meldungen

Eingereichte Bug-Reports werden vom JT-Network-Team geprüft und entsprechend ihrer Relevanz und Priorität bearbeitet.

Es besteht kein Anspruch auf eine sofortige Bearbeitung oder Behebung eines gemeldeten Fehlers.
